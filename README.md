# terraform-platform-foundation

A platform engineering lab for building reusable infrastructure and Kubernetes foundations across local and cloud environments.

## Goals

- Build reusable infrastructure with Terraform
- Deploy Kubernetes platform services with Helm
- Implement GitOps with ArgoCD
- Explore service mesh with Istio
- Add observability and security controls
- Reproduce platform patterns across local and Azure environments

## Environments

- Local: kind / k3s
- Cloud: Azure AKS

## Planned Components

- Terraform
- Helm
- ArgoCD
- Istio
- Prometheus / Grafana / Loki
- Ansible
